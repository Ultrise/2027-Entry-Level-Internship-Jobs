## About this directory

This repository is a small, curated snapshot of software engineering internships, graduate roles, and entry-level technology jobs. It is a discovery list that points to **Ultrise**, where job details and availability are maintained.

This is a **10-role pilot**, not a complete job board. Listings can close at any time, so the Ultrise job page is the source of truth.

### Why Ultrise?

- Jobs are aggregated directly from company career pages.
- Listings are kept up to date on [ultrise.com](https://www.ultrise.com).
- You apply through the employer's official application page.
- No resume harvesting and no stale reposts.

### How to use this list

1. Open a role in the table above.
2. Review the full description, requirements, and location details on Ultrise.
3. Continue to the employer's official application page from Ultrise.
